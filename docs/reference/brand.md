# Brand assets

Aberration's mark uses two opposing angular forms. Its geometry is kept in the
repository's assets/brand/logo.svg master; the folder also contains plain black
and white SVGs and the adaptive favicon for reuse.

<img class="brand-reference" src="../assets/brand/logo-black.svg" width="96" height="96" alt="Aberration mark">

## Placement and colour

The application header uses the mark as a link to dashboard home. It is black
in light mode and white in dark mode, including when appearance is set explicitly.
Authentication and error pages use the same home link. The link has an accessible
name and a 44px interaction area.

Use the full 64 × 64 viewBox, which includes clear space. Preserve the aspect
ratio and the gap between the forms. Use solid black or white on a contrasting
surface. Keep the mark free of outlines, coloured fills, and visual effects.
